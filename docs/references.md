## Matching diagnostics

`tools/probe_slot.py` compiles one canonical source slot into private objects. It checks body size and instruction/register fields, while masking actual relocation fields for diagnostics. It leaves the complete-build objects alone. An apparent local match still requires the strict complete-unit gate; symbol placement, relocation targets and following data cannot be settled by masking.

[decomp-permuter](https://github.com/simonlindholm/decomp-permuter) was cloned locally at commit `8556c81d80d1c1af98a858c8f4dc951357f29139` under ignored `.tools/decomp-permuter`. It runs in isolated `.venv-permuter` with TOML 0.10.2. The tool can explore source forms when register allocation is the remaining difference. Candidates require a semantic/type review and the complete binary gate before integration; mechanically improved scores can still produce unsuitable source. Its MIT license remains in the tool checkout. The first private experiment uses the saved archive-parser near-match at `analysis/us/main/permuter_333cc` and includes stack/branch differences in scoring.

The archive-parser permutation experiment is historical: natural C now passes the full build under PsyQ 4.6 `-G8`. Private probes accept `--compiler shipped|psyq40|esa45|psyq46|gcc272` and `--g 0|8` for C slots. Reports name the actual compiler and additional flags. C++ slots retain their separate compiler; the C-profile option rejects them. These options change only the running diagnostic process, leaving canonical compiler settings untouched.

The original [zlib 1.1.3 source archive](https://zlib.net/fossils/zlib-1.1.3.tar.gz) is retained under ignored `analysis/references/`. Its SHA-256 is `cae5847bc0e1cf113d3f70d037400da3e47c2e2b7b1c96b0b08447a5fbb906f4`. The version string, stream size and original inflate algorithms provide evidence for the embedded runtime's structures and function names. Each recovered implementation still requires byte matching; a version string alone does not prove an unmodified library.
